Axis letters

          

          

            Filament winders have no standard axis lettering, so these are
            configurable. Defaults follow the lathe convention (ISO 841), with
            the frame oriented so forward rotation is +C:
          

          
    
            
  • X — radial cross-feed. Horizontal, pointing front
              (toward the operator).
    • 
            
  • Y — vertical, up. Completes the right-handed frame;
              nothing is emitted on it, as there is no second linear radial
              axis.
    • 
            
  • Z — carriage, along the mandrel axis. Note
              +Z points opposite the direction the carriage advances —
              that follows from the right-hand rule once +C is chosen, so the
              carriage travels in −Z. The 3D view draws it that way rather than
              hiding it.
    • 
            
  • A — payout eye rotation, about X.
    • 
            
  • C — mandrel rotation, about Z. Forward spin is +C;
              switch it on the Design tab under Machine.
